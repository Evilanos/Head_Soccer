# Head Soccer (kontrol pakai HP)

1. `npm install` (sekali saja), lalu `npm start` — atau klik dua kali `start.bat`.
2. Buka `http://localhost:3000/host` di PC/laptop/TV (layar utama).
3. HP (Wi-Fi yang sama) scan QR di layar atau buka alamat yang tertera, masukkan kode room.
4. Pilih mode 1v1 / 2v2, level bot, durasi → MULAI.

Slot yang tidak diisi HP dimainkan bot. Klik slot di lobby untuk pakai keyboard
(Keyboard 1: A D W + S/Spasi, Keyboard 2: panah + ↓/Enter).
Jika HP tidak bisa konek: izinkan Node.js di Windows Firewall (jaringan Private).

## Karakter & jurus
- Di HP: tombol **🎨 Karakter & Jurus** (halaman masuk, atau di lobby) → pilih jurus, warna kulit, gaya rambut, warna rambut, aksesori.
- Meter jurus terisi seiring waktu (±13 dtk) dan saat menyentuh bola. Penuh → tombol **JURUS** menyala.
- 🔥 Bola Api · ❄️ Bekukan · 💪 Raksasa · ⚡ Kilat · 💥 Gempa · 🧲 Magnet
- Keyboard: jurus = **E** (Keyboard 1) / **/** (Keyboard 2). Bot juga memakai jurus acak.
